# 🚗 BMW Sales Dashboard — Power BI

## 📊 Project Overview

This project is an interactive **BMW Sales Dashboard** created using Microsoft Power BI.

The dashboard is designed to analyze customer and sales-related patterns using demographic, vehicle, payment, mileage, price-category, and yearly sales information.

The main data table used in the report is **`Clean_BMW`**.

## 🎯 Objectives

- Analyze BMW customer distribution and sales-related patterns.
- Understand customer demographics such as age group and gender.
- Explore customer distribution across BMW models.
- Analyze customers by sale year.
- Compare customers across mileage categories.
- Analyze payment-mode usage.
- Understand distribution across different price categories.
- Provide interactive filters for deeper analysis.

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** — Data cleaning and preparation
- **DAX** — Calculated measures and analysis
- **Data Visualization** — KPI Cards, Slicers, Pie Chart, Column Chart, Funnel Chart, Bar Chart and Donut Chart

## 📌 Dashboard Components

### KPI Cards

The dashboard contains KPI-style cards for:

- Customer count by model
- Customer count by state
- Customer count by age group
- Customer count by sale year

### Interactive Filters

The dashboard provides slicers for:

- Gender
- Mileage Category
- Payment Mode

### Visual Analysis

The report includes:

- **Price Category** distribution
- **BMW Model** customer distribution
- **Gender** analysis
- **Age Group** analysis
- **Customer by Year** analysis

## 🔍 EDA Questions

This dashboard can be used to answer questions such as:

1. How are customers distributed across BMW models?
2. Which age groups contribute to the customer base?
3. How does customer distribution vary by gender?
4. How are customers distributed across mileage categories?
5. Which payment modes are used by customers?
6. How are customers distributed across different price categories?
7. How does the customer base change by sale year?
8. How do the dashboard insights change when multiple filters are applied together?
